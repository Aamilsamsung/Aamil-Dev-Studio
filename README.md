# Aamil Dev Studio

Faceless developer-studio portfolio showcasing websites, Python automation, AI/API integrations, and selected GitHub projects.

## Stack
Static HTML, CSS and vanilla JavaScript. No server, secrets, external dependencies or build step required.

## Local preview
Open `index.html` in a browser, or run `python -m http.server 8000` and visit http://localhost:8000.

## Deployment to Vercel
Import this GitHub repository at https://vercel.com/new. Select **Other** for framework, leave build command empty, and deploy the repository root. Connect the production branch `main` for automatic deployments on push.

## Contact
All enquiries are addressed to **aamil.dev@gmail.com**. The contact form uses a `mailto:` URL; the visitor must send the drafted email in their email client. It does **not** submit server-side or store any personal information on this site.

## Business information
Prices are indicative starting rates, not guarantees or binding quotes. Project descriptions link to experimental/development repositories and make no claim of production readiness.

## Editing
- Services and work descriptions: `index.html`
- Styling: `styles.css`
- Contact behaviour: `script.js`
- Security headers: `vercel.json`
