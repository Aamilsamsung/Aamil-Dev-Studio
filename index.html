No. Listed prices are starting estimates. Each project receives a custom quote after the requirements are clear.

Do hosting and API fees come with the package?

Third-party hosting, domains, paid API usage and ongoing maintenance are quoted separately unless expressly included.

AI tools may support implementation. Final deliverables still require code review, testing, and verification against the agreed scope.
